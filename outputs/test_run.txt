- test7.banana is an intentional negative runtime test. It uses an undefined variable and verifies that the interpreter reports the variable name in a clear error message.
- tests/cases/05_invalid_input.banana checks lexical error handling using an invalid character. The interpreter reports the error location without displaying a Python traceback.
- Parser tests also include invalid syntax cases, such as a missing expression or closing parenthesis. These tests verify that syntax errors are reported clearly.
